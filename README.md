# 2D横版闯关小游戏
技术栈：Unity C#
功能：玩家移动跳跃、敌人碰撞、生命值系统、发射子弹、计时、得分系统

## 项目说明
1. 经典横版闯关玩法，包含角色移动、跳跃
2. UI面板：分数Score、生命值、子弹数量Fire、倒计时Time
3. 碰撞检测：敌人、平台、终点判定
4. 打包平台：Windows
